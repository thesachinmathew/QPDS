CO2 AT2 - SCHEMA ANALYSIS AND VIVA VOCE
10 separate Python programs

SETUP:
No package installation is required. These programs use Python's built-in sqlite3 library.

RUN:
Open this folder in VS Code. In the terminal, run:
python 01_student_course_registration_odd_2026.py

Replace the filename to run another question. Each program is independent and creates an in-memory SQLite database with sample records.

SOURCE NOTE:
Question 3 in the supplied assignment lists the fields to retrieve (customer name, product name and quantity), but the uploaded text does not show a filter condition. The program therefore retrieves these fields for all orders.

DATE NOTE:
Question 4 uses SQLite's current-month date comparison. The sample appointment records include dates in November 2026 to demonstrate the query for the current month.
